## Getting Started (5 minutes)

### Step 1: Extract & Navigate
```bash
unzip FINAL_SUBMISSION.zip
cd credit-risk-model
```

### Step 2: Setup Environment
```bash
# Create virtual environment
python -m venv .venv

# Activate it
.venv\Scripts\activate          # Windows
# OR
source .venv/bin/activate       # Mac/Linux

# Install dependencies
pip install -r requirements.txt
```

### Step 3: Review Documentation
```bash
# Read project overview
cat README.md

# View submission checklist
cat SUBMISSION_CHECKLIST.md

# Read final report (PDF)
reports/final_report.pdf
```

### Step 4 (Optional): Run the Pipeline
```bash
# Train all models and generate artifacts
python main_train.py

# Run tests
pytest tests/ -v

# Launch API locally
python -m uvicorn src.api.main:app --reload
# Visit http://localhost:8000
```

### Step 5 (Optional): Use Docker
```bash
# Start all services (API + MLflow)
docker-compose up

# In another terminal:
curl http://localhost:8000/health

# View MLflow at http://localhost:5000
```

## Key Results

### Model Performance
| Model | PR-AUC | F1 Score | Selected |
|-------|--------|----------|----------|
| **Logistic Regression** | **0.82** | **0.76** | ✅ YES |
| Random Forest | 0.81 | 0.75 | - |
| XGBoost | 0.80 | 0.73 | - |

**Rationale:** Highest PR-AUC + interpretability for regulatory requirements

### Features Engineered
- **Customer Activity:** Transaction counts, sums, averages by period
- **Temporal Patterns:** Hour, day, month, year, day-of-week features
- **Risk Indicators:** Fraud rate per customer, negative transaction flags
- **Total:** 42 features ready for modeling

### Proxy Target
- **Method:** K-Means clustering on RFM (Recency/Frequency/Monetary)
- **Result:** Binary classification (high-risk vs. low-risk)
- **Justification:** Alternative to unavailable ground truth default labels

## Troubleshooting

### Issue: Python/pip not found
**Solution:** Ensure Python 3.10+ is installed and in PATH
```bash
python --version
```

### Issue: Dependencies installation fails
**Solution:** Use upgraded pip
```bash
.venv\Scripts\python.exe -m pip install --upgrade pip
pip install -r requirements.txt
```

### Issue: Tests fail with sklearn errors
**Solution:** Verify environment setup
```bash
pip list | grep scikit-learn
# Should show scikit-learn version
```

### Issue: Docker not running
**Solution:** Install Docker Desktop and enable WSL2
```bash
docker --version
docker-compose --version
```
